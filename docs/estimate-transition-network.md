# 遷移ネットワーク可視化 — 方式別見積もり（比較用）

**用途:** 上長向け比較表の原資。方式ごとに **独立した見積時間** を並べる。  
**注意:** 4方式の時間を **合算しない**（採用はいずれか1つ想定。比較のためにそれぞれ算出している）。  
**前提:** 要件定義・設計書あり。実装はゼロから。第三者実装。ダミーデータ。現行スパイク相当の機能。  
**単位:** 時間（h）  
**作成日:** 2026-07-27

**大項目の意味**

| 大項目 | 意味 |

| 共通基盤 | どの方式でも同じ土台（プロジェクト・画面枠） |

## 4. 上長説明用の短い文言例

- 本見積は **方式ごとの代替案比較** であり、4方式をすべて実装する合計ではない。  
- 工数だけ見ると **Cytoscape（108h）＝ AG Charts（108h） ≒ GoJS（112h）＜ スクラッチ（164h）**。  
- AG Charts の工数は Cytoscape 並みだが、**表現・機能は異なる**（Chord／圏外なし）。ネットワーク見た目が必須なら Scratch / Cytoscape / GoJS が本線。  
- スクラッチはライセンス費用なしだが、実装時間が最も長い。  
- Cytoscape は無料でネットワーク要件を満たしやすい。GoJS は有償だが同系統の工数。

## 5. 数値の根拠（要約）

- 現行スパイク成果物の構成から工程を積み上げた **経験ベース見積**（実測ログではない）。  
- AG Charts の方式本体は **Cytoscape と同程度（76 h）**。  
- スクラッチが長い理由: SVG・幾何・PNG を自前実装するため。
